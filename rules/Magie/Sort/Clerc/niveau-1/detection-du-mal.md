# Détection du mal

**Niveau :** 1
**Portée :** Rayon de 18 m ou plus
**Durée :** 6 tours
**Jet de sauvegarde :** Volonté vs DD du test d’incantation (parfois)
**Temps d’incantation :** 1 action

## Général
Le clerc brandit son symbole sacré et détecte les émanations du mal dans un rayon de **1,5 m** de large qui s’étend sur **18 m** (ou plus) devant le symbole.

La définition du mal est basée sur le clerc : généralement, elle englobe les créatures d’alignement opposé, celles qui sont impies pour la divinité du clerc et celles qui ont une intention clairement nuisible. Selon la puissance du sort, il peut détecter des dangers encore plus subtils. Ce sort ne révèle pas les créatures qui sont autrement cachées, mais il informe le clerc que des intentions maléfiques émanent d’une certaine position.

Ce sort peut être inversé pour détecter le bien, c’est-à-dire les créatures d’alignement allié, de divinité commune ou ayant des objectifs sacrés similaires.

## Résultats du test d’incantation

| Test | Résultat |
|---:|---|
| 1–11 | **Échec.** |
| 12–13 | Les créatures d’alignement opposé sont potentiellement détectées, ainsi que les objets intrinsèquement dangereux (comme les pièges et les armes maudites). Les créatures maléfiques bénéficient d’un jet de sauvegarde de **Volonté** contre le DD du test d’incantation pour ne pas être détectées. |
| 14–17 | Les créatures d’alignement opposé sont automatiquement détectées, ainsi que les objets intrinsèquement dangereux. Les créatures maléfiques ne bénéficient pas d’un jet de sauvegarde. |
| 18–19 | Dans un rayon de **36 m** dans toutes les directions, les créatures d’alignement opposé sont automatiquement détectées, ainsi que les objets intrinsèquement dangereux. |
| 20–23 | Le clerc est immédiatement conscient de toutes les créatures et objets maléfiques dans un rayon de **54 m**. De plus, les créatures et objets maléfiques brillent d’une faible lueur surnaturelle évidente pour les alliés du clerc. |
| 24–27 | Comme ci-dessus (rayon de **54 m**). De plus, le clerc est également conscient des créatures ayant des intentions nuisibles à son égard, même si elles ne sont pas d’alignement opposé (ex. une araignée agressive ou un ours affamé). |
| 28–29 | Comme ci-dessus (rayon de **54 m**). Les créatures détectées par ce sort sont blessées par la lumière de la vérité, subissant une pénalité de **-1** à tous les jets d’attaque, jets de dégâts, tests de compétence, tests d’incantation et jets de sauvegarde tant qu’elles sont à portée. |
| 30–31 | Le clerc est immédiatement conscient de toutes les créatures et objets maléfiques dans un rayon de **72 m**. Les créatures détectées subissent une pénalité de **-2** à tous leurs jets et tests tant qu’elles sont à portée. |
| 32+ | Le clerc est immédiatement conscient de toutes les créatures et objets maléfiques dans un rayon de **90 m**. Les créatures détectées subissent une pénalité de **-4** à tous leurs jets et tests tant qu’elles sont à portée. |
