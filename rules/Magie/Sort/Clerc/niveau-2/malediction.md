# Malédiction

**Niveau :** 2  
**Portée :** Vue  
**Durée :** Variable  
**Jet de sauvegarde :** Volonté vs DD du test d’incantation  
**Temps d’incantation :** 1 round  

## Général
Le clerc prononce une malédiction profonde à l’encontre d’une autre créature, qui bénéficie toujours d’un jet de sauvegarde de Volonté pour résister. Ce sort doit être utilisé avec précaution, car il est considéré comme un acte d’intervention puissant de la part d’une divinité. Prononcer des malédictions sévères, telles que celles qui affectent des familles ou des communautés entières ou qui s’étendent sur des générations, est considéré comme un péché. Des rituels plus longs entraînant des temps d’incantation plus importants peuvent être appropriés pour des malédictions plus sinistres.

## Résultats du test d’incantation

| Test | Résultat |
|---:|---|
| 1–13 | **Échec.** |
| 14–15 | Le clerc lance une malédiction simple sur une cible qui inflige une pénalité de -1 à la Chance pendant 24 heures. |
| 16–19 | Le clerc lance une malédiction sur une cible qui inflige une pénalité de -2 à la Chance et une pénalité de -1 à une autre statistique au choix du clerc pendant une durée allant jusqu’à une semaine. La statistique peut être les jets d’attaque, les jets de dégâts, une caractéristique, les jets de sauvegarde, les tests d’incantation, la Classe d’Armure, la vitesse (où -1 = -1,5 m), les points de vie, etc. |
| 20–21 | Le clerc lance une malédiction sur une cible qui inflige une pénalité de -2 à la Chance et une pénalité de -2 à une autre statistique au choix du clerc pendant une durée allant jusqu’à une semaine. La statistique peut être les jets d’attaque, les jets de dégâts, une caractéristique, les jets de sauvegarde, les tests d’incantation, la Classe d’Armure, la vitesse (où -1 = -1,5 m), les points de vie, etc. Alternativement, le clerc peut choisir d’invoquer une limitation physique ou mentale spécifique pendant une semaine. Par exemple, la cible ne peut pas parler, ne peut pas marcher, ne peut pas dormir, ne peut pas voir, etc. |
| 22–25 | Le clerc lance une malédiction sur une cible qui inflige une pénalité de -2 à la Chance, une pénalité de -2 à une autre statistique et une limitation physique ou mentale spécifique (ex : ne peut pas parler, dormir, voir, marcher, etc.). La statistique peut être les jets d’attaque, les dégâts, une caractéristique, les jets de sauvegarde, les tests d’incantation, la Classe d’Armure, la vitesse (où -1 = -1,5 m), les points de vie, etc. La durée est permanente jusqu’à ce qu’une condition spécifique soit remplie. La condition doit avoir un sens pour la divinité du clerc ou la cible, et elle doit être réalisable par la cible (même si elle est très difficile). Par exemple : « tu ne verras pas tant que tu n’auras pas embrassé la reine méduse » ou « tu ne dormiras pas tant que tu n’auras pas fermé les yeux sous le tombeau du démon sans sommeil ». |
| 26–29 | Le clerc lance une malédiction sur un groupe de personnes : une famille, une communauté, un village, un groupe d’aventuriers, etc. Le clerc peut affecter jusqu’à 10 personnes à la fois tant qu’elles font partie d’un seul groupe défini. La malédiction inflige une pénalité de -2 à la Chance, une pénalité de -2 à une autre statistique et une limitation physique ou mentale spécifique (ex : ne peut pas parler, dormir, voir, marcher, etc.). La statistique peut être les jets d’attaque, les dégâts, une caractéristique, les jets de sauvegarde, les tests d’incantation, la Classe d’Armure, la vitesse (où -1 = -1,5 m), les points de vie, etc. La durée est permanente jusqu’à ce qu’une condition spécifique soit remplie. |
| 30–31 | Le clerc lance une malédiction sur un grand groupe de personnes : une famille, une communauté, un village, un groupe d’aventuriers, les résidents d’un château, etc. Le clerc peut affecter jusqu’à 50 personnes à la fois tant qu’elles font partie d’un seul groupe défini. La malédiction inflige une pénalité de -2 à la Chance, une pénalité de -2 à deux autres statistiques et une limitation physique ou mentale spécifique (ex : ne peut pas parler, dormir, voir, marcher, etc.). La statistique peut être les jets d’attaque, les dégâts, une caractéristique, les jets de sauvegarde, les tests d’incantation, la Classe d’Armure, la vitesse (où -1 = -1,5 m), les points de vie, etc. La durée est permanente jusqu’à ce qu’une condition spécifique soit remplie. |
| 32–33 | Le clerc lance une malédiction sur un très grand groupe de personnes : une famille, une communauté, un village, un groupe d’aventuriers, les résidents d’un château, etc. Le clerc peut affecter jusqu’à 100 personnes à la fois tant qu’elles font partie d’un seul groupe défini. La malédiction inflige une pénalité de -4 à la Chance, une pénalité de -2 à trois autres statistiques et une limitation physique ou mentale spécifique (ex : ne peut pas parler, dormir, voir, marcher, etc.). La statistique peut être les jets d’attaque, les dégâts, une caractéristique, les jets de sauvegarde, les tests d’incantation, la Classe d’Armure, la vitesse (où -1 = -1,5 m), les points de vie, etc. La durée est permanente jusqu’à ce qu’une condition spécifique soit remplie. |
| 34+ | Le clerc lance une malédiction sur un groupe extrêmement large de personnes : une famille, une communauté, un village, un groupe d’aventuriers, les résidents d’un château, etc. Le clerc peut affecter jusqu’à 1 000 personnes à la fois tant qu’elles font partie d’un seul groupe défini. De plus, la malédiction se transmet aux héritiers des personnes affectées et se propage à travers les générations jusqu’à ce qu’elle soit levée. La malédiction inflige une pénalité de -4 à la Chance, une pénalité de -2 à trois autres statistiques et une limitation physique ou mentale spécifique (ex : ne peut pas parler, dormir, voir, marcher, etc.). La statistique peut être les jets d’attaque, les dégâts, une caractéristique, les jets de sauvegarde, les tests d’incantation, la Classe d’Armure, la vitesse (où -1 = -1,5 m), les points de vie, etc. La durée est permanente jusqu’à ce qu’une condition spécifique soit remplie. |
