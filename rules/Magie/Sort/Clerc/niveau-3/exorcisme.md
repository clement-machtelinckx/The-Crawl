# Exorcisme

**Niveau :** 3
**Portée :** 1,5 km par NI
**Durée :** Instantanée
**Jet de sauvegarde :** Voir ci-dessous
**Temps d’incantation :** 1 heure

## Général
Le clerc fait appel aux forces divines pour briser les liens unissant les mortels et leurs patrons surnaturels, au risque d'attirer une attention indésirable sur lui-même. Ce sort ne peut être accompli qu'une fois tous les sept jours après une période de jeûne et de prière.

Un objet appartenant à la cible ou un élément physique (cheveux, sang, ongle, etc.) est généralement requis. Tenter le sort sans un tel lien impose une **pénalité de -4** au test d'incantation et réduit la portée à **30 m par NI**. Si le test d'incantation du clerc dépasse celui effectué lors de la création du lien original, le lien est rompu et le sujet perd immédiatement tous les avantages associés (y compris les sorts de patron). Le sujet ne peut pas tenter de reformer le lien avant un mois. Si le test est insuffisant, le clerc doit réussir un test de **Chance** pour éviter le courroux du patron impliqué.

## Résultats du test d’incantation

| Test | Résultat |
|---:|---|
| 1–15 | **Échec.** Le clerc doit réussir un test de **Chance (DD 5)** sous peine d'attirer l'attention du patron, alertant le sujet de la tentative. |
| 16–17 | Le clerc exorcise un lien dont le test d'incantation original était inférieur au sien. Le sujet est **hébété** pendant **1d6 rounds** (pénalité de -2). En cas d'échec de rupture, test de **Chance (DD 10)** sous peine de voir un agent mineur du patron traquer le clerc (arrivée sous 1d5 jours). |
| 18–21 | Le clerc exorcise le lien. Le sujet est **paralysé** pendant **1d6 rounds**. En cas d'échec de rupture, test de **Chance (DD 12)** sous peine de voir un agent mineur du patron traquer le clerc (arrivée sous 1d4 jours). |
| 22–23 | Le clerc exorcise le lien. Le sujet subit **1d6 + NI** dégâts. En cas d'échec de rupture, test de **Chance (DD 14)** sous peine de voir un agent moyennement puissant du patron traquer le clerc (arrivée sous 1d3 jours). |
| 24–26 | Le clerc exorcise le lien. Le sujet subit **1d8 + NI** dégâts et perd temporairement 1 point de caractéristique. En cas d'échec de rupture, test de **Chance (DD 16)** sous peine de voir un agent moyennement puissant du patron traquer le clerc (arrivée sous 1d2 jours). |
| 27–31 | Le clerc exorcise le lien. Le sujet subit **1d10 + NI** dégâts, perd temporairement 1 point de caractéristique et perd l'usage d'un sort aléatoire pour la journée. En cas d'échec de rupture, test de **Chance (DD 18)** sous peine de voir un agent moyennement puissant traquer le clerc (arrivée sous 1d2 jours). |
| 32–33 | Le clerc exorcise le lien. Le sujet subit **2d6 + NI** dégâts, perd 2 points de caractéristique et doit réussir un jet de **Volonté** sous peine de perdre conscience pendant **1d6 heures**. En cas d'échec de rupture, test de **Chance (DD 20)** sous peine de voir un agent puissant traquer le clerc (arrivée immédiate). En cas de succès du test de Chance, le clerc subit un contrecoup cosmique (malediction mineure). |
| 34–35 | Le clerc exorcise le lien. Le sujet subit **3d6 + NI** dégâts, perd 3 points de caractéristique et doit réussir un jet de **Volonté** ou perdre tous ses sorts pour 24 heures. En cas d'échec de rupture, test de **Chance (DD 22)** sous peine de voir un agent extrêmement puissant traquer le clerc (arrivée sous 1d12 heures). |
| 36+ | Le clerc exorcise le lien. Le sujet doit réussir un jet de **Vigueur (DD 22)** ou subir une transformation physique horrifiante (monstre, pierre, etc.). En cas de succès, il subit **3d8 + NI** dégâts, perd 4 points de caractéristique temporaires et 1 point **permanent**. En cas d'échec de rupture, le patron apparaît instantanément pour détruire le clerc. |
