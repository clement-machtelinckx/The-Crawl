# Nom secret

**Niveau :** 3
**Portée :** 30 m par NI ou illimitée
**Durée :** Instantanée
**Jet de sauvegarde :** Volonté vs DD du test d’incantation
**Temps d’incantation :** 1 action

## Général
Le clerc fait appel à sa divinité pour révéler le nom véritable d’un individu ou d’une créature, ce qui lui permet d’affecter plus facilement sa cible avec sa magie. Ce sort ne fonctionne que sur les créatures intelligentes et les constructions magiques nommées par leur créateur. Un succès au jet de sauvegarde de **Volonté** cache le nom véritable. Pour connaître ce nom, le clerc doit être à portée et voir clairement la cible, ou posséder un objet personnel ou un composant physique (sang, cheveux, etc.). S'il possède un composant physique, la portée est illimitée sur le même plan. Une fois le nom véritable connu, le clerc bénéficie de manière permanente des avantages du test d'incantation.

## Résultats du test d’incantation

| Test | Résultat |
|---:|---|
| 1–15 | **Échec.** |
| 16–17 | Le clerc apprend un soupçon du nom secret mineur de la cible. Celle-ci subit une **pénalité de -1** à tous ses jets de sauvegarde contre les sorts du clerc. |
| 18–21 | Le clerc apprend la prononciation exacte du nom secret mineur. La cible subit une **pénalité de -2** à tous ses jets de sauvegarde contre les sorts du clerc. |
| 22–23 | Le clerc apprend le nom secret majeur. La cible subit une **pénalité de -3** aux jets de sauvegarde. De plus, toutes les tentatives de domination ou de renvoi (*exorcisme*, *exil*, *injonction*, etc.) bénéficient d'un **bonus de +2** au test d'incantation. |
| 24–26 | Le clerc apprend le nom secret majeur. La cible subit une **pénalité de -3** aux jets de sauvegarde. Les tentatives de domination ou de renvoi bénéficient d'un **bonus de +3**. |
| 27–31 | Le clerc apprend le véritable nom secret. La cible subit une **pénalité de -4** aux jets de sauvegarde. Les tentatives de domination ou de renvoi bénéficient d'un **bonus de +4**. Tous les autres tests d'incantation contre cette cible gagnent un bonus de **+1**. |
| 32–33 | Le clerc apprend le véritable nom secret. La cible subit une **pénalité de -4** aux jets de sauvegarde. Les tentatives de domination ou de renvoi bénéficient d'un **bonus de +4**. Tous les autres tests d'incantation contre cette cible gagnent un bonus de **+2**. |
| 34–35 | Le clerc apprend le nom véritable et ceux de tous les parents de sang vivants. Tous les membres de la famille subissent une **pénalité de -5** aux jets de sauvegarde. Bonus de **+5** pour la domination ou le renvoi, et **+3** pour les autres tests d'incantation contre la cible. |
| 36+ | Le clerc apprend le nom véritable de la dynastie entière (vivants, morts ou à naître). Tous les membres subissent une pénalité égale à **-5** ou **-(NI + 2)** (la plus élevée) aux jets de sauvegarde. Tous les tests d'incantation contre la cible ou sa lignée bénéficient d'un bonus de **+4** ou **+(NI + 2)** (le plus élevé). |
