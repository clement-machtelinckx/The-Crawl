# Alphabet runique (mortel)
**Niveau :** 1  
**Portée :** 1 rune inscrite  
**Durée :** Jusqu'au déclenchement  
**Jet de sauvegarde :** Volonté vs test d'incantation ; -1 si la cible a un alignement opposé  
**Temps d’incantation :** 1 tour (10 minutes)  

## Général
Les mages apprennent des alphabets de symboles magiques qui, lorsqu'ils sont tracés, provoquent des choses incroyables. Avec ce sort, l'incantateur peut créer les runes les plus simples, celles compréhensibles par les mortels. L'alignement de l'incantateur est imprégné dans la rune. L'incantateur trace le signe à l'aide de matériaux rares et coûteux (50 po par rune). La rune peut être tracée sur n'importe quel objet : broche, livre, pierre tombale, porte, etc. Soustrayez -2 au test pour la tracer en l'air, -4 pour la rendre invisible ou -8 pour la rendre permanente.

## Revers
Lancer 1d4 : (1) une rune déterminée au hasard explose sur la main de l'incantateur ; (2) la rune est tracée mais ne s'activera pas, agissant seulement comme un tatouage coûteux ; (3) l'incantateur trace par inadvertance un symbole permanent qui ressemble à une silhouette de son visage ; (4) l'incantateur oublie comment lire et écrire pendant 1d6 tours.

## Corruption
Lancer 1d4 : (1) l'incantateur a une forme runique non magique gravée en permanence sur une joue ; (2) le front de l'incantateur se ride comme pour abriter un troisième œil ; (3) mineure ; (4) majeure.

---

## Résultats du test d’incantation
| Test | Résultat |
| --- | --- |
| 1 | Échec, perdu et pire encore ! Lancez 1d6 modifié par la Chance : (0 ou moins) corruption + marque du patron + revers ; (1-2) corruption ; (3) marque du patron (ou corruption si pas de patron) ; (4+) revers. |
| 2-11 | Perdu. Échec. |
| 12-13 | Alarme. Une alarme sonore retentit lorsque l'objet cible est dérangé (pas de sauvegarde). Alternativement, l'alarme peut avertir l'incantateur mentalement dans un rayon de 1,5 km. |
| 14-17 | Message. La rune récite un message prédéterminé lorsqu'elle est déclenchée (pas de sauvegarde). |
| 18-19 | Blocage. Les créatures jusqu'à la taille humaine sont incapables de passer à travers ou à côté de l'objet cible (Volonté DD test d'incantation pour résister). |
| 20-23 | Immobilité. Les créatures tentant de déplacer l'objet cible ne peuvent pas le soulever ou le bouger (Volonté DD test d'incantation pour résister). |
| 24-27 | Véracité. Les créatures ne peuvent pas mentir ou tromper en vue de cette rune (Volonté DD test d'incantation pour résister). |
| 28-29 | Oubli. Les créatures voyant l'objet cible oublient qu'il existe dès que leur attention s'en détourne (Volonté DD test d'incantation pour résister). |
| 30-31 | Sommeil. Les créatures voyant la rune tombent dans un sommeil normal (Volonté DD test d'incantation pour résister). |
| 32+ | Malédiction. La rune inflige une malédiction mineure à la créature qui la voit (Volonté DD test d'incantation pour résister). La malédiction draine 1d3 points de Chance. |
