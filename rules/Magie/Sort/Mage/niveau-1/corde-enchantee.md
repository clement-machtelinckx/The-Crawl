# Corde enchantée
**Niveau :** 1  
**Portée :** 9 m ou plus  
**Durée :** Variable  
**Jet de sauvegarde :** Aucun (Spécial)  
**Temps d’incantation :** 1 round  

*L'incantateur invoque une corde éthérée ou matérielle pour exécuter ses ordres.*

## Effet
Invoque une corde capable de s'animer pour emmêler des ennemis, servir de pont, escalader des obstacles ou transporter des charges.

## Limites / précisions
- **Flexibilité :** Contrairement aux autres sorts, permet de choisir **n'importe quel résultat inférieur** au test d'incantation.
- **Résistance :** La corde peut supporter jusqu'à **200 kg**.

## Revers
Lancer 1d4 : (1) repousse les cordes (**1d4 h**) ; (2) ligoté par sa propre corde (**Force DD 15**) ; (3) alliés liés ensemble dans un nœud ; (4) 1d4 cordes animées agressives (**CA 8, 5 PV, Atk +3**).

## Corruption
Lancer 1d4 : (1) peau aspect corde ; (2) bras tentacules (+10-20 cm) ; (3) sixième doigt ; (4) sixième orteil.

---

## Résultats du test d’incantation
| Test | Résultat |
| --- | --- |
| 1 | Échec, perdu et pire encore ! (Table des revers/corruption). |
| 2-11 | Perdu. Échec. |
| 12-13 | Invoque une corde (**30 m**) pendant **1 tour**. |
| 14-17 | Idem, peut se réorganiser en formes (symboles, écritures). |
| 18-19 | Idem, peut **emmêler une cible** (Réf vs DD test pour s'échapper). |
| 20-23 | Idem, s'élève en l'air (pont/échelle). Supporte **200 kg**. |
| 24-27 | Idem, soulève une cible (**15 m/round**). |
| 28-29 | Idem, peut traîner une cible (**9 m/round**). |
| 30-31 | Portée étendue à **90 m**. |
| 32+ | Durée augmentée à **1 heure**. |
