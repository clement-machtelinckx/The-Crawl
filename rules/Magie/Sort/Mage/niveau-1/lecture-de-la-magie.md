# Lecture de la magie
**Niveau :** 1  
**Portée :** 1,5 m  
**Durée :** Variable  
**Jet de sauvegarde :** Aucun  
**Temps d’incantation :** 1 round  

*L'incantateur déchiffre les écrits ésotériques, parchemins et runes mystiques.*

## Effet
Permet de comprendre le sens des textes magiques sans pour autant activer leurs effets. Indispensable pour utiliser des parchemins. L'incantateur peut aussi apprendre l'inverse : *obscurcissement magique*.

## Limites / précisions
- **Cible :** Textes, inscriptions sur objets (épées, arches), parchemins ou grimoires.

## Revers
Lancer 1d6 : (1) incapable de lire (**1d4 jours**) ; (2) vision brouillée des alliés (**1d3 h**) ; (3) texte proche devient magique (lisible uniquement via ce sort) ; (4) 1d6 pages déformées ; (5) traduction aléatoire d'un livre ; (6) paroles se transforment en fumée.

## Corruption
Lancer 1d6 : (1-2) mineure ; (3) tatouages runiques brillants ; (4) voile jaune sur les yeux lors de la lecture ; (5) doigts tachés d'encre (permanent) ; (6) majeure.

---

## Résultats du test d’incantation
| Test | Résultat |
| --- | --- |
| 1 | Échec, perdu et pire encore ! (Table des revers/corruption). |
| 2-11 | Perdu. Échec. |
| 12-13 | Lecture de parchemins/livres pendant **1 tour**. Permet de lancer les sorts de parchemin. |
| 14-17 | Lecture pendant **1 tour / NI**. |
| 18-19 | Lecture pendant **1 heure**. Bonus de **+1** au test si le sort du parchemin est lancé immédiatement après. |
| 20-23 | Durée **2 heures**. Bonus de **+2** au test du parchemin. |
| 24-27 | Durée **4 heures**. Bonus de **+4** au test du parchemin. Déchiffre les inscriptions complexes. |
| 28-29 | Lecture pendant **24 heures**. |
| 30-31 | Capacité **permanente** de lire un type spécifique de texte (niveau, auteur). |
| 32+ | Capacité **permanente** de lire toute la magie. |
