# Pattes d'araignée
**Niveau :** 1  
**Portée :** Soi-même ou contact  
**Durée :** 1 tour / NI  
**Jet de sauvegarde :** Aucun  
**Temps d’incantation :** 1 action  

*L'incantateur acquiert l'agilité d'un arachnide pour grimper sur n'importe quelle surface.*

## Effet
Confère des bonus à l'escalade ou la capacité surnaturelle de marcher sur les murs et plafonds, même les mains encombrées.

## Limites / précisions
- **Conditions :** Pour les bas paliers (12-19), l'incantateur doit avoir les mains et pieds nus.
- **Immunité :** Le sort protège contre les effets de *toile d'araignée*.

## Revers
Lancer 1d5 : (1) pieds collés au sol (**Force DD 16**) ; (2) membres glissants (chute, **Agi DD 12/round**) ; (3) allié emmêlé dans de la toile ; (4) nuée d'araignées venimeuses ; (5) gravité inversée pour le mage (**pieds collés à 2,4 m du sol**).

## Corruption
Lancer 1d6 : (1) quatre membres d'araignée dans le dos ; (2) file des toiles (portée 9 m) ; (3) poils hirsutes sur tout le corps ; (4) six yeux supplémentaires ; (5) sécrétion collante et huileuse ; (6) mineure.

---

## Résultats du test d’incantation
| Test | Résultat |
| --- | --- |
| 1 | Perdu, échec et pire encore ! (Table des revers/corruption). |
| 2-11 | Perdu. Échec. |
| 12-13 | Bonus **+10** aux tests d'escalade (pieds/mains nus). |
| 14-17 | Bonus **+20** aux tests d'escalade. |
| 18-19 | **Escalade surnaturelle** (murs, plafonds, vitesse normale). Pieds/mains nus requis. |
| 20-23 | Idem, utilisable avec **gants, chaussures et objets en main**. |
| 24-27 | **Mage + 1 allié** reçoivent la capacité d'escalade. |
| 28-29 | **Mage + tous les alliés (Rayon 3 m)** reçoivent la capacité. |
| 30-31 | Idem, durée **1 heure / NI**. |
| 32+ | **Capacités totales** (Escalade, venin, toiles) pour tous les alliés (Rayon 6 m). |
