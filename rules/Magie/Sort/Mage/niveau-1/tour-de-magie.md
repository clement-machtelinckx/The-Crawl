# Tour de magie
**Niveau :** 1  
**Portée :** Variable  
**Durée :** Variable  
**Jet de sauvegarde :** Volonté vs test d'incantation (si applicable)  
**Temps d’incantation :** 1 action  

*L'incantateur manipule de petites quantités d'énergie magique pour produire des effets visuels, auditifs ou cinétiques mineurs.*

## Effet
Permet de réaliser des prouesses magiques simples : lumières, sons, petits mouvements d'objets ou légères décharges d'énergie.

## Limites / précisions
- **Polyvalence :** Peut produire tout effet décrit par l'incantateur dans les limites de puissance du test.
- **Risque :** Malgré sa faible puissance, le sort comporte les mêmes risques de revers que les sorts majeurs.

## Manifestation
Variable selon l'effet produit.

## Revers
Lancer 1d4 : (1) invoque une abeille agressive ; (2) plaque de colle sous les bottes (**Force DD 15**) ; (3) cheveux changent de couleur ; (4) yeux changent de couleur.

---

## Résultats du test d’incantation
| Test | Résultat |
| --- | --- |
| 1 | Échec, perdu et revers. |
| 2-11 | Perdu. Échec. |
| 12-13 | **Effet visuel simple** (Portée **6 m / NI**). Ex: éclair, ténèbres, rayons. |
| 14-17 | **Effet visuel ou auditif** (basique). Ex: phrase chuchotée, aboiement. |
| 18-19 | **Effet visuel, auditif ou cinétique** (petit mouvement). Ex: renverser un verre, mélanger des cartes. |
| 20+ | **Effet total**. Inclut génération d'énergie dangereuse (**1d3 dégâts** type acide ou froid). |
