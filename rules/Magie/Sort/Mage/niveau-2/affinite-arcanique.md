# Affinité arcanique
**Niveau :** 2  
**Portée :** Soi-même  
**Durée :** Variable  
**Jet de sauvegarde :** Aucun  
**Temps d’incantation :** Variable (souvent 1 semaine d'étude)  

*L'incantateur se spécialise dans une école de magie profane pour en accroître la maîtrise.*

## Effet
Le mage lie son essence à un domaine spécifique (nécromancie, pyromancie, etc.). Cela lui permet de lancer certains sorts thématiques avec une puissance accrue, souvent au prix de la maîtrise d'autres sorts ou de sa propre santé.

## Limites / précisions
- **Spécialisation :** Le choix de l'école est définitif une fois le sort réussi.
- **Équilibre :** Gagner un dé supérieur pour un sort nécessite souvent de réduire le dé d'un autre sort (système de dé de test DCC).
- **Sacrifice :** Les hauts paliers de maîtrise exigent souvent un sacrifice permanent de **Points de Vie**.

## Revers
Non applicable directement (voir échec critique).

## Corruption
Lancer 1 naturel : L'affinité échoue et l'incantateur subit automatiquement une corruption.

---

## Résultats du test d’incantation
| Test | Résultat |
| --- | --- |
| 1-13 | **Échec.** |
| 14-15 | **Affinité nominale**. **+1 dé** pour un sort thématique / **-1 dé** pour un autre sort. |
| 16-19 | **Affinité forte**. **+1 dé** pour deux sorts thématiques / **-1 dé** pour un autre. |
| 20-21 | **Affinité puissante**. Apprend un **sort bonus** de l'école choisie. Perte permanente de **1 PV**. |
| 22-25 | **Compréhension réelle**. Apprend un sort bonus (**-1 PV**) ET **+1 dé** pour deux sorts connus / **-1 dé** pour un autre. |
| 26-29 | **Maître de spécialité**. **+1 dé** pour trois sorts / **-1 dé** pour deux autres. Perte permanente de **1 PV**. |
| 30+ | **Grand Maître**. **+1 dé** pour trois sorts / **-1 dé** pour un seul. Emplacement de sort gratuit (**-1 PV**). |
