# Bouche magique
**Niveau :** 2  
**Portée :** Contact  
**Durée :** Jusqu'au déclenchement  
**Jet de sauvegarde :** Aucun  
**Temps d’incantation :** 1 tour  

## Général
L'incantateur insuffle un message dans un objet, lequel sera prononcé lorsqu'une condition spécifique est remplie.

## Revers
Lancer 1d4 : (1) la bouche insulte bruyamment l'incantateur dès sa création ; (2) la bouche crie constamment au lieu d'attendre sa condition ; (3) la bouche déforme le message pour dire le contraire ; (4) la bouche se fixe sur la main de l'incantateur au lieu de l'objet.

## Corruption
Lancer 1d6 : (1-3) mineure ; (4-5) majeure ; (6) plus grande.

---

## Résultats du test d’incantation
| Test | Résultat |
| --- | --- |
| 1 | Échec, perdu et pire encore ! Lancez 1d6 modifié par la Chance : (0 ou moins) corruption + marque du patron + revers ; (1-2) corruption ; (3) marque du patron (ou corruption si pas de patron) ; (4+) revers. |
| 2-11 | Perdu. Échec. |
| 12-13 | La bouche prononce un message simple (10 mots max) quand l'objet est touché. |
| 14-17 | Message de 25 mots max avec une condition de déclenchement simple (proximité, contact). |
| 18-19 | Message long (1 minute de parole) avec une condition plus complexe (détection visuelle, audition). |
| 20-23 | La bouche peut engager une conversation rudimentaire (3 questions/réponses). |
| 24-27 | La bouche peut imiter la voix d'une personne spécifique. |
| 28-29 | Plusieurs bouches sur différents objets se déclenchent les unes les autres. |
| 30-31 | La bouche peut lancer un sort mineur ou un cri qui assourdit (Vig DD test d'incantation). |
| 32+ | La bouche est douée d'une intelligence limitée et peut surveiller une zone de façon permanente. |
