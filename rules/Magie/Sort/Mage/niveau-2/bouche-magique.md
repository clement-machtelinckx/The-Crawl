# Bouche magique
**Niveau :** 2  
**Portée :** Contact  
**Durée :** Jusqu'au déclenchement  
**Jet de sauvegarde :** Aucun  
**Temps d’incantation :** 1 tour  

*L'incantateur insuffle un message vocal dans un objet inanimé, programmé pour s'activer.*

## Effet
Fait apparaître une bouche sur un objet pour délivrer un message lorsque les conditions de déclenchement sont remplies.

## Limites / précisions
- **Déclenchement :** Doit être spécifié lors de l'incantation (visuel, auditif, contact).
- **Conversation :** À partir du palier 20, la bouche peut répondre de manière rudimentaire.

## Revers
Lancer 1d4 : (1) bouche insultante dès sa création ; (2) crie en continu (pas d'attente) ; (3) déforme le message (sens inverse) ; (4) se fixe sur la main du mage.

## Corruption
Lancer 1d6 : (1) bégaiement permanent du mage ; (2) la bouche du mage prend une forme grotesque pendant 1d4 jours ; (3) le mage répète involontairement chaque phrase qu'il entend ; (4) la voix du mage change pour celle de la bouche magique ; (5) majeure ; (6) plus grande.

## Résultats du test d’incantation
| Test | Résultat |
| --- | --- |
| 1 | Échec, perdu et pire encore ! (Table des revers/corruption). |
| 2-11 | Perdu. Échec. |
| 12-13 | **Message simple** (10 mots). Déclenchement par **toucher**. |
| 14-17 | **Message modéré** (25 mots). Déclenchement simple (proximité/contact). |
| 18-19 | **Message long** (1 minute). Condition complexe (détection visuelle/auditive). |
| 20-23 | **Conversation** (3 questions/réponses rudimentaires). |
| 24-27 | **Imitation parfaite** de la voix d'une personne connue. |
| 28-29 | **Réseau**. Plusieurs bouches se déclenchant en chaîne. |
| 30-31 | **Bouche offensive**. Peut lancer un sort mineur ou un **cri assourdissant** (Vig DD test). |
| 32+ | **Sentinelle**. Intelligence limitée et surveillance permanente. |
