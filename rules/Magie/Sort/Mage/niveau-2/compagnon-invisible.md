# Compagnon invisible
**Niveau :** 2  
**Portée :** 15 m  
**Durée :** Variable  
**Jet de sauvegarde :** Aucun  
**Temps d’incantation :** 1 tour  

## Général
L'incantateur invoque un esprit invisible pour le servir.

## Revers
Lancer 1d4 : (1) l'esprit invoqué est malveillant et commence par voler un objet à l'incantateur ; (2) l'esprit refuse d'obéir et s'en va ; (3) l'esprit est visible et ridicule, attirant les moqueries ; (4) l'esprit confond l'incantateur avec son ennemi.

## Corruption
Lancer 1d6 : (1-3) mineure ; (4-5) majeure ; (6) plus grande.

---

## Résultats du test d’incantation
| Test | Résultat |
| --- | --- |
| 1 | Échec, perdu et pire encore ! Lancez 1d6 modifié par la Chance : (0 ou moins) corruption + marque du patron + revers ; (1-2) corruption ; (3) marque du patron (ou corruption si pas de patron) ; (4+) revers. |
| 2-11 | Perdu. Échec. |
| 12-13 | Un compagnon invisible apparaît pour une tâche simple de 1d6 rounds. |
| 14-17 | Le compagnon reste pendant 1 tour et peut effectuer des tâches manuelles simples. |
| 18-19 | Le compagnon reste pendant 1 heure. Il est assez fort pour porter des objets (For 10). |
| 20-23 | Le compagnon reste pendant un jour. Il peut servir de garde ou de guetteur. |
| 24-27 | Plusieurs compagnons invisibles (1d4) apparaissent pour aider l'incantateur. |
| 28-29 | Le compagnon est puissant (For 18) et peut combattre. Durée 1 heure. |
| 30-31 | Le compagnon est permanent jusqu'à sa destruction ou sa révocation. |
| 32+ | L'incantateur invoque une armée de compagnons invisibles pour accomplir une grande tâche. |
