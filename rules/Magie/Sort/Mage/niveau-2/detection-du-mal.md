# Détection du mal
**Niveau :** 2  
**Portée :** 15 m ou plus  
**Durée :** 1 tour ou plus  
**Jet de sauvegarde :** Volonté (parfois)  
**Temps d’incantation :** 1 action  

*L'incantateur perçoit les intentions malveillantes, les objets maudits ou les présences impies.*

## Effet
L'incantateur perçoit les émanations de malveillance dans son environnement. 
**Note :** S'agissant d'un sort de clerc adapté, le mage subit une pénalité de **-2** à ses tests d'incantation.

## Limites / précisions
- **Concentration :** Requise pour maintenir la détection.
- **Obstacles :** Le plomb ou les protections magiques bloquent la vision.

## Revers
Lancer 1d4 : (1) mal interprété (le bien semble mal) ; (2) aveuglement par la "noirceur" (**1d4 rounds**) ; (3) attire l'attention de l'entité maléfique détectée ; (4) cauchemars récurrents (**-1 aux tests** le lendemain).

## Corruption
Lancer 1d6 : (1-3) mineure ; (4-5) majeure ; (6) plus grande.

---

## Résultats du test d’incantation
| Test | Résultat |
| --- | --- |
| 1 | Échec, perdu et pire encore ! (Table des revers/corruption). |
| 2-13 | Perdu. Échec. |
| 14-17 | Détecte le mal dans un rayon de **18 m**. |
| 18-19 | Détecte le mal (rayon **18 m**) et identifie la source exacte. |
| 20-23 | Rayon **30 m**. Perçoit la puissance relative du mal. |
| 24-27 | Rayon **30 m**. Les créatures maléfiques subissent **-1 aux attaques** tant qu'elles sont détectées. |
| 28-29 | Peut suivre une **trace maléfique** (passage < 24 h). |
| 30-31 | Portée **Ligne de vue**. Sonde les pensées malveillantes (Volonté DD test). |
| 32+ | **Vision divine**. Perçoit tout le mal à perte de vue pendant **un jour**. |
