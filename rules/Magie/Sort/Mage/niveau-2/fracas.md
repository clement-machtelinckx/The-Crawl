# Fracas
**Niveau :** 2  
**Portée :** Contact ou plus  
**Durée :** Instantanée  
**Jet de sauvegarde :** Aucun  
**Temps d’incantation :** 1 round  

## Général
L'incantateur brise un objet physique. Ce sort cause des dégâts aux objets inanimés et est particulièrement efficace sur le cristal ou le verre.

## Revers
Lancer 1d5 : (1) un objet aléatoire sur l'incantateur se brise ; (2) un allié aléatoire voit ses objets ordinaires risquer de se briser (magiques 10%, métal/pierre 25%, bois/cristal 50%, tissu 75%) ; (3) l'objet visé est renforcé au lieu d'être brisé ; (4) toutes les armes à 7,5 m se brisent (sauf si rangées) ; (5) toutes les armures à 7,5 m perdent leur bonus de CA (sangles qui lâchent, boucles qui cassent).

## Corruption
Lancer 1d6 : (1-3) mineure ; (4-5) majeure ; (6) plus grande.

---

## Résultats du test d’incantation
| Test | Résultat |
| --- | --- |
| 1 | Échec, perdu et pire encore ! Lancez 1d6 modifié par la Chance : (0 ou moins) corruption + marque du patron + revers ; (1) corruption ; (2) marque du patron (ou corruption si pas de patron) ; (3+) revers. |
| 2-11 | Perdu. Échec. |
| 12-13 | Échec, mais le sort n'est pas perdu. |
| 14-15 | L'incantateur crée une fissure par contact sur un objet mondain, infligeant 1d4 points de dégâts. Brise un bouton de porte, une charnière ou un petit miroir. |
| 16-19 | Par contact. Inflige 3d4 points de dégâts (+2 si verre/cristal). Brise une épée, un bouclier, une roue de chariot ou un joyau de valeur. |
| 20-21 | Par contact. Inflige 3d6 + niveau d'incantateur points de dégâts (+4 si verre/cristal). Brise une porte, fend une armure de plaques ou un diamant. |
| 22-25 | Par contact. Inflige 4d6 + niveau d'incantateur points de dégâts (1d6 pour les objets magiques). |
| 26-29 | Par contact ou imprégnation sur un objet (flèche, dague). Inflige 4d8 + niveau d'incantateur points de dégâts (2d6 pour objets magiques). |
| 30-31 | Comme ci-dessus, mais le sort reste imprégné pendant 1 tour. |
| 32-33 | Portée de 18 m. Inflige 4d8 + niveau d'incantateur points de dégâts (3d6 + niveau pour objets magiques). |
| 34+ | Portée de 300 m. Peut cibler les golems et automates. Inflige 6d8 + niveau d'incantateur points de dégâts (4d6 + niveau pour objets magiques). |
