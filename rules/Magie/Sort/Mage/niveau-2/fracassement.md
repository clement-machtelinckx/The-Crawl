# Fracassement
**Niveau :** 2  
**Portée :** Contact ou plus  
**Durée :** Instantanée  
**Jet de sauvegarde :** Aucun  
**Temps d’incantation :** 1 round  

*L'incantateur libère une vibration destructrice pour briser les objets solides.*

## Effet
Inflige des dégâts massifs aux objets inanimés. Particulièrement efficace contre le cristal, le verre et, à haut niveau, les automates.

## Limites / précisions
- **Nature :** Ne cible que les objets inanimés (sauf palier 34+ pour les golems).
- **Matériaux :** Bonus de dégâts contre le verre et le cristal.
- **Magie :** Les objets magiques subissent des dégâts réduits.

## Revers
Lancer 1d5 : (1) objet du mage se brise ; (2) objets alliés menacés (check %) ; (3) renforce l'objet visé ; (4) toutes les armes à 7,5 m se brisent ; (5) toutes les armures à 7,5 m perdent leur CA.

## Corruption
Lancer 1d6 : (1-3) mineure ; (4-5) majeure ; (6) plus grande.

---

## Résultats du test d’incantation
| Test | Résultat |
| --- | --- |
| 1 | Échec, perdu et pire encore ! (Table des revers/corruption). |
| 2-11 | Perdu. Échec. |
| 12-13 | Échec simple (sort non perdu). |
| 14-15 | Contact. **1d4** dégâts (objet mondain). Brise un petit mécanisme. |
| 16-19 | Contact. **3d4** dégâts (**+2** vs verre). Brise arme, bouclier ou joyau. |
| 20-21 | Contact. **3d6 + NI** dégâts (**+4** vs verre). Fend une porte ou armure lourde. |
| 22-25 | Contact. **4d6 + NI** dégâts (**1d6** pour objets magiques). |
| 26-29 | Imprégnation (arme). **4d8 + NI** dégâts (**2d6** pour objets magiques). |
| 30-31 | Idem, mais l'arme reste imprégnée **1 tour**. |
| 32-33 | Portée **18 m**. **4d8 + NI** dégâts (**3d6 + NI** pour objets magiques). |
| 34+ | Portée **300 m**. **6d8 + NI** dégâts. Cible les **golems et automates**. |
