# Chien occulte
**Niveau :** 3  
**Portée :** 9 m  
**Durée :** Variable  
**Jet de sauvegarde :** Aucun  
**Temps d’incantation :** 1 tour  

## Général
L'incantateur invoque un chien spectral pour le garder ou traquer ses ennemis.

## Résultats du test d’incantation
| Test | Résultat |
| --- | --- |
| 1-13 | Échec. |
| 14-15 | Chien spectral (Atk +2, 1d6 dmg, CA 12, 10 PV) pendant 1 heure. |
| 16-19 | Chien spectral (Atk +4, 1d8 dmg, CA 14, 20 PV) pendant 4 heures. |
| 20-23 | Chien capable de traquer par l'odeur magique. |
| 24-27 | Chien capable de voir l'invisible et de mordre les créatures éthérées. |
| 28-31 | Meute de 1d4 chiens occultes. |
| 32+ | Chien occulte géant (Atk +8, 2d10 dmg, CA 18, 50 PV). |
