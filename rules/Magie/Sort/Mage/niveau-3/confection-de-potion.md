# Confection de potion
**Niveau :** 3  
**Portée :** Soi-même  
**Durée :** Permanente  
**Jet de sauvegarde :** Aucun  
**Temps d’incantation :** 1d6+1 heures + récolte/brassage (min 1 semaine)  

## Général
L'incantateur crée des mixtures mystiques qui accordent des pouvoirs surnaturels. Le coût est de (résultat du test / 2) x 25 po. Le juge lance secrètement le dé de test.

## Revers
Lancer 1d4 : (1) la potion explose (1d10 dmg, Vig pour demi-dégâts) ; (2) aucun effet magique ; (3) effet inverse ; (4) durée divisée par deux.

## Résultats du test d’incantation
| Test | Résultat |
| --- | --- |
| 1-15 | Échec. |
| 16-17 | Potion d'amour, poison. |
| 18-21 | Contrôle des animaux, forme gazeuse, soins. |
| 22-23 | Rétrécissement, croissance, lévitation, respiration aquatique. |
| 24-26 | Métamorphose, vitesse, héroïsme. |
| 27-31 | Invisibilité, contrôle des humains, résistance au feu. |
| 32-33 | Contrôle des morts-vivants, soins extraordinaires, vol. |
| 34-35 | Super-héroïsme, force de géant. |
| 36+ | Longévité, invulnérabilité. |
