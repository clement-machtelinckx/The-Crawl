# Limier occulte
**Niveau :** 3  
**Portée :** 9 m  
**Durée :** Variable  
**Jet de sauvegarde :** Aucun  
**Temps d’incantation :** 1 tour  

*L'incantateur invoque un gardien spectral canin pour la protection ou la traque.*

## Effet
Conjure un chien d'ombre fidèle. À haut niveau, le limier peut traquer les traces magiques, voir l'invisible ou se transformer en une meute de chasseurs spectraux.

## Limites / précisions
- **Statistiques :** Le limier possède ses propres caractéristiques de combat (Atk, CA, PV) qui augmentent avec le test.

## Revers
Non applicable directement (échec simple).

## Corruption
Voir règles de corruption standard pour les invocations.

---

## Résultats du test d’incantation
| Test | Résultat |
| --- | --- |
| 1-13 | **Échec.** |
| 14-15 | **Chien spectral** (Atk +2, 1d6 dmg, CA 12, 10 PV). Durée **1 heure**. |
| 16-19 | **Chien spectral** (Atk +4, 1d8 dmg, CA 14, 20 PV). Durée **4 heures**. |
| 20-23 | Capacité de **traquer l'odeur magique**. |
| 24-27 | Capacité de **voir l'invisible** et mordre les éthérés. |
| 28-31 | **Meute de 1d4 chiens** occultes. |
| 32+ | **Limier Géant** (Atk +8, 2d10 dmg, CA 18, 50 PV). |
