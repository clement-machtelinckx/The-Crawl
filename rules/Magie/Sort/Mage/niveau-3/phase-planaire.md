# Phase planaire
**Niveau :** 3  
**Portée :** Potentiellement infinie  
**Durée :** Permanente  
**Jet de sauvegarde :** Volonté vs test (si involontaire)  
**Temps d’incantation :** 1 round ou plus (voir tableau)  

*L'incantateur traverse l'espace et les dimensions d'un seul pas mystique.*

## Effet
Permet la téléportation instantanée. À bas niveau, le mage se déplace sur le même plan ; à haut niveau, il peut voyager vers d'autres dimensions ou transporter des armées entières.

## Limites / précisions
- **Familiarité :** Le risque d'erreur dépend de la connaissance du lieu de destination.
- **Erreur :** Une erreur de téléportation entraîne une déviation de plusieurs kilomètres.

## Revers
Lancer 1d4 : (1) déviation de **1,5 à 15 km** (direction aléatoire) ; (2) permutation des membres du groupe ; (3) possessions téléportées ailleurs (mage nu) ; (4) armes du groupe téléportées ailleurs.

## Corruption
Lancer 1d8 : (1) vieillit de **100 ans** ; (2) désancré (disparaît **1d4 rounds** sur un 13 naturel) ; (3) aimant dimensionnel (attire démons/élémentaires) ; (4-8) majeure ou supérieure.

## Résultats du test d’incantation
| Test | Résultat |
| --- | --- |
| 1 | Échec, perdu et pire encore ! (Table des revers/corruption). |
| 2-11 | Perdu. Échec. |
| 12-15 | Échec simple (sort non perdu). |
| 16-17 | **Destination connue (150 km)**. Déviation : **1d10 miles - NI**. Risque arrivée (20% : **1d4** dmg). |
| 18-21 | Portée **300 km**. Peut emmener **1 créature**. |
| 22-23 | Portée **750 km**. Peut emmener **4 créatures**. |
| 24-26 | Portée **3000 km** ou lune/planète proche. |
| 27-31 | **Zone (Rayon 12 m)**. Transfert sur le plan ou plan adjacent. |
| 32-33 | **Mage + alliés (12 m)** vers **n'importe quel plan**. |
| 34-35 | **Masse** (navires, armées, cités). Temps : **1 tour à 1 semaine**. Coût : **5-20 pts spellburn**. |
| 36+ | **Précision absolue**. Peut créer un **portail permanent** (50 000 po+, 10 pts spellburn). |
