# Respiration aquatique
**Niveau :** 3  
**Portée :** Contact  
**Durée :** Variable  
**Jet de sauvegarde :** N/A  
**Temps d’incantation :** 1 round  

*L'incantateur adapte les poumons d'une cible pour lui permettre de survivre sous l'eau.*

## Effet
Confère la capacité de respirer dans un milieu aquatique. Le sort inverse permet de respirer normalement dans un air toxique ou dépourvu d'oxygène.

## Limites / précisions
- **Nature :** Ne confère pas de bonus de nage ou de vision sous-marine aux bas paliers.

## Revers
Lancer 1d3 : (1) mage respire **uniquement** sous l'eau (**1 round**, noyade possible à l'air libre) ; (2) allié respire de l'eau (**1d4** dmg) ; (3) attire un monstre marin (**3 DV**).

## Corruption
Lancer 1d4 : (1) ouïes dans le cou ; (2) mains/pieds palmés ; (3) écailles ; (4) mineure.

---

## Résultats du test d’incantation
| Test | Résultat |
| --- | --- |
| 1-15 | **Échec.** |
| 16-17 | **1 cible** pendant **1 tour**. |
| 18-21 | **1 cible** pendant **1 heure**. |
| 22-25 | **2 cibles (1 h)** OU **1 cible (4 h)**. |
| 26-31 | **4 cibles (4 h)** OU **1 cible (24 h)**. |
| 32+ | **8 cibles (24 h)** OU **1 cible permanente**. |
