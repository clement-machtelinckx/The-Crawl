# Transfert
**Niveau :** 3  
**Portée :** 3 m par niveau  
**Durée :** Variable  
**Jet de sauvegarde :** Volonté pour annuler  
**Temps d’incantation :** 1 round  

## Général
L'incantateur prend possession d'un autre corps, temporairement ou de façon permanente.

## Revers
Lancer 1d5 : (1) toutes les surfaces réfléchissantes à 4,5 m éclatent ; (2) échange d'âme avec un animal inoffensif (rat, oiseau) pendant 1d3 rounds ; (3) cible la mauvaise victime ; (4) l'incantateur tombe dans le coma pendant 1d4 rounds ; (5) retour psychique (tout le monde peut lire l'esprit du mage pendant 1d4 heures).

## Corruption
Lancer 1d4 : (1) vieillit de 1 an ; (2) regard hypnotique horrible ; (3) parle en langues inconnues par intermittence ; (4) reflet dans le miroir d'une autre personne.

---

## Résultats du test d’incantation
| Test | Résultat |
| --- | --- |
| 1 | Échec, perdu et pire encore ! Lancez 1d6 modifié par la Chance : (0 ou moins) corruption + marque du patron + revers ; (1-2) corruption ; (3) marque du patron (ou corruption si pas de patron) ; (4+) revers. |
| 2-11 | Perdu. Échec. |
| 12-15 | Échec, mais le sort n'est pas perdu. |
| 16-17 | Contrôle des actions d'une cible pendant (niv) rounds. Volonté chaque round pour résister. |
| 18-21 | Possession d'une victime endormie jusqu'à 8 heures (1d8 + mod Int). La victime se réveille épuisée. |
| 22-23 | Possession totale (cible rate son jet de Volonté). Le corps du mage est inerte (coma). Changements physiques mineurs sur le corps possédé. Durée 1 round par niveau. |
| 24-26 | Comme ci-dessus, durée 1 tour par niveau. |
| 27-31 | Comme ci-dessus, durée 1 heure par niveau. Le mage peut sauter de corps en corps à volonté (chaque nouvelle cible a droit à un jet de Volonté). |
| 32-33 | Comme ci-dessus, durée 4 heures par niveau. |
| 34-35 | Le mage peut transférer son âme dans un réceptacle préparé (coût 500 po par décennie). Le corps physique meurt. Le mage peut tenter de posséder toute créature s'approchant du réceptacle (test 22+). |
| 36+ | Oblitération immédiate de l'âme de la victime et possession permanente de son corps. Le corps d'origine du mage est détruit par combustion spontanée. |
